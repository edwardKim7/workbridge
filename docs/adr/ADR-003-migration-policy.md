# ADR-003: CSV 정상 행만 반영하고 동일 파일은 차단

- 상태: 승인

## 배경

한 CSV 안에 정상 행과 오류 행이 섞일 수 있습니다. 한 행의 오류 때문에 전체 파일을 버리거나, 검증 전에 고객 테이블에 바로 반영하는 방식은 둘 다 문제가 있었습니다.

## 결정

1. 모든 행을 Staging에 저장합니다.
2. 행별 정규화와 검증 결과를 남깁니다.
3. 오류 행은 고객 테이블에 반영하지 않습니다.
4. 정상 행 전체는 하나의 트랜잭션으로 INSERT 또는 UPDATE합니다.
5. 오류가 있더라도 정상 반영이 끝나면 `COMPLETED_WITH_ERRORS`로 기록합니다.
6. 정상 반영 트랜잭션이 실패하면 전체 정상 집합을 롤백하고 `FAILED`로 기록합니다.
7. 완료된 파일과 같은 SHA-256 값은 `409`로 차단합니다.

## 이유

오류 행은 원본과 행 번호를 남기고, 정상 데이터는 한 번에 반영할 수 있습니다. 같은 파일이 실수로 다시 적용되는 것도 막을 수 있습니다.

## 대안

- 오류 한 건이면 전체 롤백: 정상 행까지 다시 준비해야 합니다.
- 행마다 즉시 반영: 중간 실패 시 어디까지 적용됐는지 확인하기 어렵습니다.
- 파일명으로 중복 판단: 이름만 바꾸면 우회할 수 있습니다.

## 제한

현재 파일 크기는 5MB로 제한합니다. 더 큰 파일이 필요하면 업로드와 실행을 분리하고 비동기 배치로 바꾸는 편이 적합합니다.
